# HOLLOW V1 — Level layout

**Prototypeområde:** ca. 240 × 240 m, justeres efter faktisk ydelse. Koordinater er designvejledende meter (x,z), ikke endelige krav.

| Lokation | Ca. (x,z) | Formål |
|---|---|---|
| A — Ankomst/bil | (0,0) | Intro, kontroller, checkpoint |
| B — Forgrening | (25,45) | Giver et rigtigt rutevalg |
| C — Træbro | (75,70) | Hurtigere, men højlydt |
| D — Skråning | (30,110) | Længere rute med dækning |
| E — Skovfogedhytte | (110,145) | Radio, strøm, interiør, checkpoint |
| F — Generatorskur | (140,155) | Udendørs antennelink |
| G — Veranda/skjul | (105,157) | Undvigelsesmekanik |
| H — Sikker passage | (175,205) | Slutsekvens |

## Ruter
**Kort og støjende:** A → B → C → E.
**Lang og skjult:** A → B → D → E.
**Risikofase:** E ↔ F, mulig brug af G.
**Afslutning:** E/F → H.

Begge tilgange skal være spilbare og føles forskelligt. Terrænet skal have naturlige pejlemærker, skovvariation og mulighed for at orientere sig uden konstante UI-markører.

## Huset
Fuld indgang, en central stue med radio og notesbog, elpanel, tydelig forbindelse til generatoren, side-/udgangsdør og et sted at skjule sig. Alle dør- og kollisionsflader skal testes.

## Afgrænsning
Ingen ekstra store huse eller helt nye biomer i V1. Anvend arbejdstid på hytten, skovstier, tåge, lys og missionens logiske sammenhæng.
